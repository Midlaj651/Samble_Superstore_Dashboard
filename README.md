
# 🛒 Superstore Sales Analysis Dashboard | Tableau

## 📌 Project Overview
<img width="1641" height="1039" alt="image" src="https://github.com/user-attachments/assets/640e9fd3-a582-4195-9566-834da114bd3d" />


The Superstore Dashboard is a data analytics project developed using Tableau to analyze sales performance, profitability, customer behavior, product performance, shipping costs, and geographical sales distribution.

The dashboard provides interactive visualizations and key performance indicators (KPIs) to help stakeholders understand business performance and identify opportunities for improvement.

## 🎯 Project Objectives

- Analyze overall sales and profit performance.
- Monitor order volume and customer growth.
- Identify top-performing products and markets.
- Evaluate regional and geographical sales performance.
- Analyze shipping costs and logistics performance.
- Understand customer purchasing behavior.
- Track annual sales and profit trends.
- Support data-driven business decisions.
